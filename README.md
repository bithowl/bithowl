# Who I Am

I am an independent offensive security researcher with a primary focus on vulnerability discovery and responsible disclosure. My work revolves around understanding how modern systems fail, identifying security weaknesses before attackers do, and documenting practical research that helps improve defensive security.

Rather than relying solely on automated scanners, I spend significant time analyzing application behavior, business logic, authentication flows, and implementation details to uncover vulnerabilities that are often overlooked.
